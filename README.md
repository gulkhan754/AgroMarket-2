# AgroMarket 2.0 🌿

Учебный интернет-магазин с новым дизайном, каталогом, корзиной, регистрацией, входом и личным кабинетом.

## Запуск в VS Code

1. Откройте папку `AgroMarket_2` в VS Code.
2. Откройте Terminal → New Terminal.
3. Выполните `npm install` (нужен интернет при первой установке).
4. Выполните `npm run dev` — запустятся два сервера.
5. Откройте **http://localhost:3000** в браузере.

**Не запускайте через Live Server**: авторизация работает через Node.js на порту 3000. Каталог загружается через Fetch API из json-server на порту 3001.

## Функции

- 24 товара из `db.json`, DOM и Fetch API
- Поиск, категории, сортировка, фильтр цен
- Корзина с количеством и суммой; сохранение в localStorage
- Регистрация и вход через Node.js + bcryptjs (пароли хранятся в виде хешей)
- Личный кабинет, выход и история демонстрационных заказов
- Обработка ошибок загрузки

## Важно

Это **учебный проект для локального запуска**, а не готовый сервис для публикации в интернет. Для продакшена нужны HTTPS, постоянное хранилище сессий, защита от CSRF, ограничение попыток входа и секрет сессии из переменных окружения. Данные пользователей и заказов записываются в `data/` и исключены из Git через `.gitignore`.

Фотографии подгружаются с Unsplash и требуют интернет. Оформление заказа — демонстрационное, без оплаты и доставки.
